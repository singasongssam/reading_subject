# reading_subject
교과연계 독서 전략 설계 에이전트


## AI 결합 (개인 키 방식)
- 로그인 후 상단 **개인 AI 설정**에서 Gemini API 키 등록/삭제. 브라우저 탭 세션에 저장됩니다.
- 키 없음: 기존 규칙 기반으로 자료/지도안 생성.
- 키 있음: 수준별 읽기자료와 이해/추론/비평 질문, 교사 발문, 학생 활동, 평가 기준에 Gemini 사용.
- 교육과정 데이터와 가네 9사태의 순서·시간·기본 구조는 규칙 엔진을 유지합니다.
- **주의:** GitHub Pages는 정적 호스팅이므로 키가 브라우저에서 Gemini로 직접 전송됩니다. 키를 안전하게 숨기는 방식이 아니며, 공용 PC 사용을 피하고 키 제한/사용량을 모니터링해야 합니다. 실제 운영에는 인증된 서버 프록시 권장.
- Firebase 웹 키는 AI 키와 별개이며, 별도 제한 검토 및 기존 키 교체 작업이 필요합니다.


## AI 생성 상태와 맞춤형 수업 설계 (2026-10)

- 개인 Gemini 키가 없으면 기존 규칙 기반 결과를 생성합니다.
- 키가 있으면 읽기자료(문단·어휘·질문)와 지도안 재생성(교사 발문·학생 활동·평가 기준)에 AI를 사용합니다.
- 마법사 Step 2에서 학급 특성, 수업 강조점, 선호 수업 방식, 추가 요구를 입력할 수 있습니다. AI 재생성에 이 조건을 반영합니다. 실명·민감정보는 입력하지 마세요.
- 마법사 Step 2/Step 4에 AI 생성 성공, 규칙 기반 생성, AI 실패 후 규칙 기반 대체를 표시합니다.
- Gemini 연결 오류는 30초 제한 후 규칙 기반으로 대체합니다. 교육과정 원문, 가네 사태 구조와 시간 배분은 기존 규칙 기반 로직을 유지합니다.
- 이 프로젝트는 브라우저에서 Gemini를 직접 호출하기 때문에 개인 API 키가 해당 브라우저 사용자에게 노출될 수 있습니다. 배포 전 서버 프록시/인증과 Firebase 설정 보안 점검이 필요합니다.


## AI 생성 흐름 점검
- 개인 Gemini 키가 없는 경우 규칙 기반 읽기자료 및 가네 9사태 지도안을 사용합니다.
- 개인 키가 있는 경우 읽기자료 생성 뒤 **Step 4에서 지도안 재생성 버튼을 반드시 클릭**해야 본문에 맞는 발문 및 학생 활동이 AI로 갱신됩니다.
- 교육과정 핵심 아이디어·내용 요소, 가네 9사태 구조·시간 배분은 규칙을 유지합니다.
- Gemini 응답 지연 시 65초 제한을 적용하며, 일시적 네트워크/서버 오류에 한해 최대 한 번 재시도합니다. 그 외 오류는 규칙 기반으로 대체하며 표시합니다.
- 사용자 API 키는 브라우저에서 사용되므로 개발자 도구에서 확인 가능합니다. API 키를 공개 저장소에 넣지 마세요.
