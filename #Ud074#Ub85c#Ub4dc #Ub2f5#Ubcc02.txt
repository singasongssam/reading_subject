사회과.ttl, 과학과.ttl, 선택 교과 교육과정.ttl, 수학과 교육과정.ttl은 중학교 교육과정, 
가네.ttl은 수업지도절차,
 text.ttl은 수업시간에 활용할 다양한 텍스트 유형, 
readstrategy.ttl은 텍스트와 수업시간에 적용한 독서전략임이 파일을 중심으로 구글 안티그래비티2.0으로 시스템 개발하고자함. 
관리자 로그인, 일반교사이용자 로그인 필요, 데이터베이스는 firebase에 저장, 기타 프론트엔드는 github에 탑재, 
오프라인 상태에서 테스트 적용후 깃허브에 업로드, 우선 2과목에 해당하는 시스템을 개발한 뒤 과목 교육과정 추가, 
그 외에 ttl 파일 수정 보완, 일반교사이용자는 간단하게 id 패스만으로 접근 가능하도록. 
일반교사 모드에서는 사회과, 과학과 교육과정의 단원, 성취기준, 요소 등으로 접근하면 수업시간에 적합한 읽기자료 생성, 읽기자료에 적합한 독서전략, 독서전략을 적용할 가네.ttl을 바탕으로 수업지도안 작성 가능하도록 시스템 구축-----------------------

대략 이러한 정도의 내용을 MD 파일로 만들어 파일과 지침을 antigravity2.0에 주고 바이브 코딩하려한다. 이 내용외에 추가적으로 필요한 내용을 추가적으로 작성하여 가이드를 만들라

가이드 MD 파일을 만들었습니다. 5개 TTL을 실제로 열어 구조를 확인한 뒤 작성했습니다. Antigravity에는 이 MD와 TTL 5개를 함께 주고, 맨 뒤 §16의 초기 프롬프트를 그대로 붙여 넣으면 됩니다.

TTL을 확인하다 발견한 문제 (가이드 §3.3에 정리)

단원과 성취기준이 TTL에 없습니다. 교육과정 TTL은 영역, 핵심 아이디어, 내용요소까지만 있습니다. "단원·성취기준으로 접근"하려면 TTL을 확장해야 해서 §5에 확장 스키마를 설계했습니다. 성취기준 문구는 AI가 지어내지 않도록, 교육과정 원문에서 직접 입력하거나 검수하게 했습니다.
성취기준과 독서기능의 연결고리가 없습니다. 성취기준의 동사를 독서전략의 읽기 동사와 매칭해 전략을 추천하는 규칙을 추가했습니다.
독서전략에 절차나 적합 텍스트 유형 정보가 없습니다. 지도안을 쓰려면 이 속성이 필요해서 보완안을 넣었습니다.
5개 파일의 네임스페이스가 모두 다르고, 가네.ttl과 readstrategy.ttl이 ex:hasStrategy를 서로 다른 의미로 씁니다. 병합할 때 접두사를 분리하도록 했습니다.
과학과 내용요소가 "일부 예시"로 표시되어 있어 누락이 있을 수 있습니다.

요청하신 내용 외에 추가한 핵심 사항
ID/비밀번호만으로 로그인: Firebase가 이메일 기반이라, ID를 내부 가상 이메일로 변환하는 방식을 썼습니다. 이 방식에서는 비밀번호 재설정 메일이 작동하지 않으므로, 관리자 재설정 방법을 대안과 함께 적었습니다.
AI API 키 문제: GitHub Pages는 정적 호스팅이라 프론트에 키를 넣으면 노출됩니다. 대안 4가지를 비교했고, 방식을 나중에 바꿔도 화면 수정이 없도록 어댑터 구조로 설계했습니다.
오프라인 테스트: Firebase 에뮬레이터와 Mock AI 모드를 조합해 인터넷 없이 전체 흐름을 검증하게 했습니다.
Firestore 보안 규칙: 교사가 관리자 권한을 얻거나 남의 자료를 읽지 못하도록 규칙 골격과 테스트 항목을 넣었습니다.
개발 순서: 12단계(Phase 0~11)로 나누고 단계마다 완료 기준을 달았습니다. 마지막 단계에서는 코드 수정 없이 과목을 추가할 수 있는지 검증합니다.
교육적 품질 관리: 교사 검토 표시, 성취기준 범위 이탈 경고, 과학 정확성과 사회 관점 균형 체크리스트를 넣었습니다.
